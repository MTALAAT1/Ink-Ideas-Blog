# Blog Web Application

A simple blog web application built with Node.js, Express.js, and EJS. Users can create blog posts and view them through a responsive web interface.

## Features

* Create blog posts
* View blog posts
* Server-side rendering with EJS
* Express.js routing
* Responsive layout using Bootstrap
* Form handling
* Custom CSS styling

## Built With

* Node.js
* Express.js
* EJS
* JavaScript
* HTML
* CSS
* Bootstrap

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MTALAAT1/Ink-Ideas-Blog.git
```

Go to the project folder:

```bash
cd Ink-Ideas-Blog
```

Install the required packages:

```bash
npm install 
```

Run the application:

```bash
node index.js
```

Open the application in your browser:

```text
http://localhost:3000
```

## Note

This version does not use a database. Blog posts are stored in memory, so they will be lost when the server is restarted.

This project was built while learning Node.js, Express.js, and EJS, with the goal of understanding how a server-side web application works.
